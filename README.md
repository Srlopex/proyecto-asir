# Proyecto-ASIR - Tienda informática
Descripción: Pequeña empresa con 4 trabajadores dedicada al montaje, reparación y limpieza de equipos.

Problemas:

- La impresora solo funciona desde uno de los ordenadores.
- Los documentos importantes están guardados en un único equipo.
- Si se avería ese ordenador, podrían perder información.
- No saben qué equipos tienen ni cuándo fueron comprados.
- Proyecto dedicado a la documentación proyecto PIMA 1ºASIR
